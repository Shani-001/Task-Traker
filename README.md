
# Task Tracker

## Features
- Add tasks with empty-input validation.
- Mark tasks as Completed or Pending.
- Delete tasks.
- Display total, completed, and pending task counts.
- Filter tasks by All, Pending, and Completed.
- Save tasks and statuses in localStorage.
- Retain tasks after refreshing the browser.
- Responsive design for desktop and mobile.

## How to Run the Application

Prerequisites: Install Node.js and npm.

1. Open the project folder in a terminal.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the localhost URL displayed in the terminal, usually `http://localhost:5173`.

5. Build the application for production:

   ```bash
   npm run build
   ```

6. Preview the production build:

   ```bash
   npm run preview
   ```
